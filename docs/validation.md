## 원본 자료가 없는 환경과 구분

별도 Python 3.12 환경에서는 지하철 184 tests 실행 시 1 failure·18 errors가 발생했습니다. 원본 경계·역 자료 누락에 해당했으며 이후 데스크탑의 원본 자료 환경에서 195 tests OK를 확인했습니다. 테스트 개수 차이는 원본이 없어 초기화 단계에서 실행되지 못한 검사와 구분합니다.

환경 호환성 점검에서 pyogrio 0.13.0은 이 별도 환경의 import 단계에서 SIGBUS가 발생했고 0.12.1로 실행했습니다. pandas 2.2.3의 categorical outer join 검사는 실패했지만 3.0.6에서는 통과했습니다. 이를 모든 환경에서 재현되는 라이브러리 결함으로 일반화하지 않습니다.

## 검증하지 않은 범위

원본부터 모든 분석을 일괄 재실행한 것으로 표시하지 않습니다. 테스트 통과는 코드 검증이며 과학적 타당성 전체 또는 실제 정책 효과를 입증하는 것은 아닙니다. 정책의 운영비·승용차 전환·추가 운행 배출·순탄소효과는 시범운행 자료로 평가해야 합니다.
