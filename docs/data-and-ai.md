## AI 활용

| 도구 | 활용 범위 | 사람의 역할 |
| --- | --- | --- |
| Claude Code | 자료 수집·전처리·전체 분석 코드 작성 | 분석 기준·입력·산식·결과 해석 검토 |
| ChatGPT | 연구 질문·검증 설계·코드 및 해석 검토 | 가설·사양 결정과 결과 판단 |
| Codex | 지하철 전처리·모형 구현·실행·검증·시각화, 문서 정리 | 과학적 해석과 보고 문구 검토·승인 |

주요 지시에는 **“실제 데이터로만 계산하고, 결과가 기대와 달라도 그대로 보고해줘”**, 동결한 분석 사양을 유지한 확증검정, 인과효과·이동목적·쉼터 효과의 과장 방지 등이 포함됐습니다. 구체적인 단계별 요청·작업·검토 기록은 [AI 활용 기록](../subway/docs/analysis/ai-usage-log.md)과 [방법론 기록](../subway/docs/analysis/methodology-log.md)에 있습니다.

랜덤포레스트 5겹 교차검증과 SHAP은 예측 요인 해석에, K-평균은 행정동 분류에 사용했습니다. 예측 중요도를 인과효과로 해석하지 않습니다. 지지되지 않은 가설과 추론 불가 결과도 보존했습니다.
