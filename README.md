# AI Transportation Solution

**Team: Bumpy BuSSU**

## 프로젝트 소개

탄소중립 교통 전환 과정에서 고령자를 포함한 시민의 이동 선택권을 분석하는 데이터 분석 프로젝트입니다.

### 분석 주제

**탄소중립 교통 전환 속 고령자의 이동 선택권 격차 분석 — 공공자전거와 도시철도를 중심으로**

도시철도와 서울 공공자전거(따릉이)를 각각 분석한 뒤 결과를 통합해, 교통수단의 공급과 실제 이용 가능성 사이의 차이를 살펴봅니다.

## 분석 구조

- `subway/` — 도시철도 분석, ilwoo-maker
- `bike/` — 공공자전거(따릉이) 분석, s-min04
- `common/` — 두 분석의 공동 통합 작업

세부 분석 방법과 기술 환경은 각 영역에서 독립적으로 결정하고, 통합에 필요한 기준은 분석 진행에 맞춰 정합니다.
